# Frontend rules

Read `docs/ui_redesign_spec.md` before any UI work. It defines routes, design tokens, page
content, motion and acceptance criteria.

## Stack

- React 19, Vite 8, react-router-dom 7, TanStack Query 5, axios, recharts, lucide-react,
  Tailwind 3.4 with CSS-variable tokens in `src/index.css`.
- Dark mode: `document.documentElement.dataset.theme`, Tailwind `darkMode: ['selector', '[data-theme="dark"]']`.
  Use tokens, not raw hex values, in components.
- Lint with `oxlint` (`npm run lint`).

## Data access

- Every API call goes through `src/api/endpoints.js` using the axios client in `src/api/client.js`
  (base URL `VITE_API_BASE_URL`). Server state uses TanStack Query. No `fetch` in components.
- `localStorage` is used only for the theme preference.

## Content integrity

- Every statistic shown on the site comes from `src/content/facts.json` (value, label, source,
  publisher, year, URL). Never type a number into JSX or copy.
- Every model result shown on the site comes from `src/content/evidence.json`, generated by
  `scripts/export_site_evidence.py` from `ml/artifacts/benchmarks/`. Never hand-edit it.
- Every fact on a page renders a citation that links to the Sources section.
- Say "flags students who may need support", never "predicts who will drop out". State clearly that
  the model is not yet validated on Indian college records.
- No stock photos of students, no real names (use fictional roll numbers), no map of India.

## Design and accessibility

- Risk-tier colours are reserved for risk tiers and always paired with an icon and a text label.
- Keyboard reachable, visible focus, `prefers-reduced-motion` respected, WCAG AA contrast,
  usable at 360 px width.
- Code-split routes; public pages must not load recharts or the app bundle.

## Before finishing

- `npm run build && npm run lint` both pass. Check light and dark themes and a 360 px viewport.
- Do not add dependencies without asking. Approved for the redesign: `@fontsource-variable/newsreader`,
  `@fontsource/mukta`, `@fontsource/kalam`. `motion` only if CSS cannot do the hero sequence.
- `GeoAnalytics` and `UniversalPredictor` stay out of navigation until the owner decides.
